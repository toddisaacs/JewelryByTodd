# Catalog Structure Notes

## Page outline
1. Header / short intro
   - Title
   - One-paragraph made-to-order note
   - How to use (reference during Whatnot / DM for order)
2. Items (repeat for each style)
   - Style name
   - Photos
   - Description (weight, stone limits, exceptions)
   - Options & pricing
   - Finger size note
3. Footer / contact or “ask during show” note

## Example item fields (template)
- Style: Traditional Bezel with optional skirt
- Description: …
- Approx weight: X g
- Stone limits: …
- Metal: Silver base / Gold +$XX
- Skirt options: None / Braid / Square twist (+$XX)
- Finish: High polish / Antique / Satin
- Rhodium: +$XX (not available with antique)
- Finger size: Required
- Base price: $XXX
